# Emprega.co

Aplicativo mobile da [Emprega.co](https://empregaco.com.br), negócio de impacto social que conecta empresas a candidatos das favelas do Brasil.

## Sobre a Emprega.co

A Emprega.co atua com empregabilidade com propósito social, conectando empresas a pessoas em busca de trabalho e capacitação nas favelas de SP, PA, MA, PE, RJ, DF e MG. Seus serviços incluem terceirização de mão de obra, capacitação profissional, recrutamento e seleção, e indicação de profissionais autônomos.

## O projeto

Esta organização reúne o desenvolvimento do aplicativo mobile da Emprega.co, realizado como Trabalho de Conclusão de Curso do Técnico em Desenvolvimento de Sistemas do SENAI Suíço-Brasileira.

O aplicativo atende dois públicos:

- **Candidatos:** busca de vagas (inclusive por CEP), candidatura, perfil profissional, propostas, contratos, mensagens, treinamentos e avaliações.
- **Contratantes:** cadastro da empresa, publicação de vagas, envio de propostas, gestão de contratos e avaliações.

## Tecnologias

- **Mobile:** React Native, Expo, TypeScript, React Navigation, Zustand, Axios
- **Infraestrutura:** Microsoft Azure (homologação) e AWS (produção)
- **Qualidade:** ESLint, Prettier
- **Gestão e design:** ClickUp, Figma

## Processo de desenvolvimento

- Scrum com sprints quinzenais
- Times divididos por jornada: contratante e plataforma (Pod A) e candidato (Pod B)
- Design System próprio no Figma
- Git Flow simplificado (`main`, `develop`, `feature/*`, `bugfix/*`, `hotfix/*`)
- Conventional Commits
